# Протоколист: Корпоративное развертывание (Enterprise Guide)

Данный документ описывает архитектуру и процесс развертывания системы «Протоколист» в корпоративной среде.

## Архитектура решения

Система построена на базе **централизованного сервера обработки (AI-Hub)** и легких веб-клиентов.

1.  **Центральный сервер**:
    *   **GPU-ускорение**: Используется для быстрой транскрипции (Whisper) и работы локальных языковых моделей (Ollama).
    *   **Backend (Python/FastAPI)**: Управляет очередью задач, хранением данных и интеграциями (SMTP, Langfuse).
    *   **Nginx**: Выступает в роли реверс-прокси и веб-сервера для фронтенда.
2.  **Веб-клиенты**:
    *   Топ-менеджмент и сотрудники подключаются через любой современный браузер.
    *   Никакой установки на рабочие места пользователей не требуется.

## Технические требования

### Сервер (рекомендуемые параметры):
*   **ОС**: Linux (Ubuntu 22.04+) или Windows Server с поддержкой Docker.
*   **GPU**: NVIDIA (минимум 8 ГБ VRAM, рекомендуется RTX 3060/4060 и выше).
*   **RAM**: 16 ГБ+.
*   **Disk**: SSD (50 ГБ+ под модели и временное хранилище).

## Развертывание (Docker)

1.  **Установите Docker и NVIDIA Container Toolkit** (для поддержки GPU в контейнерах).
2.  **Склонируйте проект** на сервер.
3.  **Настройте `.env`**:
    *   Укажите `APP_PASSWORD` для защиты доступа.
    *   Настройте `SMTP_USER` и `SMTP_PASSWORD` для рассылки протоколов.
4.  **Запустите систему**:
    *   **Для сервера с GPU**:
        ```bash
        docker-compose up -d --build
        ```
    *   **Для сервера без GPU (CPU-режим)**:
        ```bash
        docker-compose -f docker-compose.cpu.yml up -d --build
        ```

## Безопасность и масштабирование

*   **Изоляция**: Все аудиозаписи обрабатываются локально на вашем сервере (On-premise), данные не передаются во внешние облака (при использовании `AI_PROVIDER=local`).
*   **Пароль**: Доступ к системе защищен общим паролем, указанным в конфигурации.
*   **Очередь**: Система автоматически ставит задачи в очередь, предотвращая перегрузку GPU.

## Поддержка
Для внесения изменений в шаблоны протоколов или интеграции с внутренними системами компании (Active Directory, Bitrix24 и др.), обратитесь к разработчику.
