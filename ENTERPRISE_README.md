# Протоколист: Корпоративное развертывание (Enterprise Guide)

Данный документ описывает архитектуру и процесс развертывания системы «Протоколист» в корпоративной среде.

## Архитектура решения

Система построена на базе **централизованного сервера обработки (AI-Hub)** и легких веб-клиентов.

1.  **Центральный сервер**:
    *   **GPU-ускорение**: Используется для быстрой транскрипции (Whisper) и работы локальных языковых моделей (Ollama).
    *   **Backend (Python/FastAPI)**: Управляет очередью задач, хранением данных и интеграциями (SMTP, Langfuse).
    *   **Nginx**: Выступает в роли реверс-прокси и веб-сервера для фронтенда.
2.  **Веб-клиенты**:
    *   Топ-менеджмент и сотрудники подключаются через любой современный браузер.
    *   Никакой установки на рабочие места пользователей не требуется.

### 🛡️ Безопасность и пароли

Система "Протоколист" спроектирована с учетом корпоративных стандартов безопасности:
1.  **Хэширование**: Пароли не хранятся в открытом виде. Используется алгоритм **SHA-256**.
2.  **Анонимизация**: Внешние метрики (Langfuse) не содержат текста совещаний (включено по умолчанию `LANGFUSE_ANONYMIZE=true`).

**Как установить пароль:**
1. Запустите файл `УСТАНОВИТЬ_ПАРОЛЬ.bat` в корне проекта.
2. Введите желаемый пароль.
3. Скопируйте полученную строку `APP_PASSWORD_HASH=...` в файл `backend/.env`.
4. Удалите старую переменную `APP_PASSWORD`, если она там была.
5. Перезапустите систему.

### 📂 Структура данных
- `uploads/`: Временная папка для загрузки аудио (очищается сразу после обработки).
- `temp_protocols/`: Папка с готовыми .docx файлами (хранятся 30 дней).
- `storage/`: База данных статусов и истории (SQLite).
- `logs/`: Технические логи работы системы (не содержат текста совещаний).

## Технические требования

### Сервер (рекомендуемые параметры):
*   **ОС**: Linux (Ubuntu 22.04+) или Windows Server с поддержкой Docker.
*   **GPU**: NVIDIA (минимум 8 ГБ VRAM, рекомендуется RTX 3060/4060 и выше).
*   **RAM**: 16 ГБ+.
*   **Disk**: SSD (50 ГБ+ под модели и временное хранилище).

### 🐧 Развертывание на Linux (через скрипты)

Для удобства работы в Linux-среде созданы скрипты автоматизации:

1.  **`START_ON_LINUX.sh`**:
    *   Автоматически определяет наличие видеокарты NVIDIA.
    *   Если GPU найден — запускает систему в Turbo-режиме.
    *   Если GPU нет — запускает в CPU-режиме.
    *   Автоматически загружает Docker-образы из папки `images/`, если они там есть.
2.  **`GET_SERVER_IP.sh`**:
    *   Показывает локальный IP сервера для подключения сотрудников.
3.  **`SET_PASSWORD.sh`**:
    *   Утилита для генерации хэша пароля (требует Python).

**Как запустить:**
```bash
chmod +x *.sh  # Разрешить выполнение
./START_ON_LINUX.sh
```

### 📂 Структура данных

*   **Изоляция**: Все аудиозаписи обрабатываются локально на вашем сервере (On-premise), данные не передаются во внешние облака (при использовании `AI_PROVIDER=local`).
*   **Пароль**: Доступ к системе защищен общим паролем, указанным в конфигурации.
*   **Очередь**: Система автоматически ставит задачи в очередь, предотвращая перегрузку GPU.
