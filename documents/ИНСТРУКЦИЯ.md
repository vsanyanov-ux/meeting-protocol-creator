# Протоколист: ИНСТРУКЦИЯ (v5.6.1)

## 🛠 Быстрый запуск
1. **Первый раз**: Запустите **Установить_Зависимости.bat** для настройки окружения.
2. **Локальный запуск (Windows)**: Используйте **Запустить_СИСТЕМУ.bat**.
3. **Docker (GPU)**: `docker-compose up -d` (требуется NVIDIA GPU).

## 🚀 Режимы развертывания
- **🐧 Linux**: Используйте `./START_ON_LINUX.sh` для запуска в Linux-среде.
- **💻 Без видеокарты (CPU)**: Запускайте через `docker-compose -f docker-compose.cpu.yml up -d`.
- **📦 Автономно (на клиенте)**: Перенесите папку проекта и запустите **START_ON_CLIENT.bat**.
- **🌐 В сети**: Используйте **GET_SERVER_IP.bat**, чтобы узнать адрес для подключения коллег.

## 🛡️ Безопасность
- Доступ к системной информации защищен паролем.
- Пароль по умолчанию: `protocolist2026` (можно изменить в `backend/.env`).

## 🤖 Выбор модели
Переключение между Yandex Cloud и локальным Whisper/Ollama настраивается в файле `backend/.env` (переменная `AI_PROVIDER`).
Поддерживается загрузка аудио/видео, а также текстовых документов (**PDF, DOCX, TXT**) для прямой генерации протокола.

## 📄 Результаты
- **Интерфейс**: [http://localhost:5177](http://localhost:5177) (Native) или [http://localhost:90](http://localhost:90) (Docker).
- **История**: Доступна прямо в интерфейсе (раздел "История").
- **Файлы**: Сохраняются в `backend/temp_protocols/`.
